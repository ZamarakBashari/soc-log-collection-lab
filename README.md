# SOC Log Collection Lab

## Overview
This repository documents my learning journey in Security Operations Center (SOC) log collection and analysis.

Log collection helps security teams monitor systems, investigate suspicious activity, and support incident response.

## Objectives
- Understand Windows and Linux security logs.
- Learn how authentication events support investigations.
- Explore log collection, forwarding, and storage.
- Practice documenting security findings.
